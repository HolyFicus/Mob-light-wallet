# 👛 Семейный кошелёк (Family Wallet)

Современное веб-приложение для удобного совместного учета семейных доходов, расходов, контроля месячных лимитов и анализа бюджета.

---

## 🚀 Публикация на GitHub и GitHub Pages

Приложение полностью адаптировано для публикации в виде статического сайта на **GitHub Pages**:
- Пути к ассетам настроены как относительные (`base: './'`), поэтому сайт корректно открывается на любом поддомене GitHub (`https://<ваш-логин>.github.io/<имя-репозитория>/`).
- Все данные сохраняются в браузере пользователя через `localStorage`.
- Встроенный финансовый ИИ-помощник работает как в серверном режиме (Gemini Flash), так и в автономном статическом режиме на GitHub Pages.
- В репозитории уже настроен автоматический CI/CD сценарий через **GitHub Actions** (`.github/workflows/deploy.yml`).

### Пошаговая инструкция по публикации:

#### 1. Создайте репозиторий на GitHub
1. Перейдите на [github.com](https://github.com) и нажмите **New Repository** (Новый репозиторий).
2. Задайте имя репозитория (например, `family-wallet`).
3. Выберите тип **Public** (Публичный) и нажмите **Create repository**.

#### 2. Загрузите код в репозиторий
Выполните команды в терминале проекта:
```bash
git init
git add .
git commit -m "Initial commit: Семейный кошелёк"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
git push -u origin main
```

#### 3. Включите GitHub Pages в настройках
1. В вашем репозитории на GitHub перейдите в **Settings** (Настройки) → **Pages**.
2. В блоке **Build and deployment** найдите пункт **Source** и выберите **GitHub Actions**.
3. Готово! GitHub автоматически запустит рабочий процесс из `.github/workflows/deploy.yml`, соберет проект и опубликует сайт.
4. Ссылка на ваш рабочий сайт появится в разделе **Settings → Pages** (обычно `https://<ваш-логин>.github.io/<имя-репозитория>/`).

## 🛠 Локальная разработка и сборка

### Установка зависимостей:
```bash
npm install
```

### Запуск локального сервера разработки:
```bash
npm run dev
```
Приложение откроется по адресу `http://localhost:3000`.

### Сборка статической версии для продакшена:
```bash
npm run build
```
Готовые статические файлы будут сгенерированы в папку `dist/`.

## ✨ Возможности приложения

- **Учет доходов и расходов**: ввод суммы, выбор категории в удобную вертикальную колонку, даты, комментария и члена семьи.
- **Месячные бюджеты**: установка лимитов на расходы по категориям с наглядной шкалой прогресса и предупреждениями о перерасходе.
- **Регулярные платежи**: учет ежемесячных счетов (аренда, ЖКХ, интернет) с уведомлениями о приближении даты оплаты.
- **Фильтрация и аналитика**: выборка по месяцам, типам операций, членам семьи и категориям.
- **Семейный ИИ-советник**: быстрый анализ бюджета, выявление перерасходов и рекомендации по экономии.
- **Резервное копирование**: экспорт и импорт всех данных в формате JSON.
- **Конфиденциальность**: данные хранятся исключительно на устройстве пользователя в `localStorage`.
